# RFCs — design proposals

Numbered, public proposals for decisions that affect architecture, licensing, or the project's
shape: data formats, dataset merges, model releases, governance rules.

Process (see `GOVERNANCE.md`): open a PR adding `rfcs/NNNN-short-name.md`; comment period
7 days; simple-majority maintainer vote. Statuses: `open for comment` → `accepted` / `rejected`.
